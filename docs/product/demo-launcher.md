# Pleos 데모 원클릭 실행 (#27)

이 Mac에서 프로젝트 폴더의 **`Pleos 데모 실행.command`**를 Finder로 연다. `두 차량이 준비됐어요`가 표시되면 기존 차량 앱에서 이어서 사용한다. 실행 위치와 폴더 이름의 공백은 상관없다. 먼저 실행한 창이 준비 중이면 두 번째 실행은 중복 실행임을 알리고 끝난다.

공유 서버와 두 전용 Pleos 차량을 재사용하며, 꺼진 차량만 기존 데이터로 다시 켠다. 차량 앱의 두 기본 서버 주소 연결도 매번 확인하고 빠진 연결을 복구한다. 기존 방·인증과 앞선 실행 증거를 보존하고 이미 열린 앱의 페이지를 유지한다. 앱 프로세스를 새로 시작하면 앱의 기본 화면으로 열린다. 음성 입력·목적지 제안·경로 요청·방 만들기와 참여는 사용자가 앱에서 직접 한다.

실행 창에는 현재 단계와 로컬 로그 경로가 나온다. 하나라도 준비되지 않으면 전체 성공 문구를 표시하지 않는다. 설정 오류·포트 충돌·부팅 지연·설치 APK 불일치는 해당 실패 문구와 함께 끝나며, 무시된 `.harness/demo/`에 기록을 남긴다. 앱 설치·권한 부여·환경 다운로드는 자동으로 하지 않는다.

최초 설정, 종료 코드와 격리 자동 검사는 [런처 운영 안내](../../prototype/vehicle/demo/README.md)를 따른다. 현재 범위는 이 Mac의 승인된 ADB5041·Pleos12Leader(5570)·Pleos12Follower(5572)·사용자10·서버4192다. 휴대폰·지도 복구·공개 배포나 음성 연속 시연·영상 제작은 포함하지 않는다.
