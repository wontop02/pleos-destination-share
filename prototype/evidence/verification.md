# 웹 첫 실행본 검증

2026-11-04, 로컬 Node 서버와 설치된 Google Chrome의 격리된 Playwright 1.64.1 문맥에서 실행했다. 개인 Chrome 프로필이나 실제 마이크 권한을 변경하지 않았다. 마이크 입력은 Chrome의 가상 장치이며 권한 거절은 주입한 NotAllowedError다. 실마이크·Safari·휴대폰·잠금/백그라운드 수신·실제 내비 실행은 검증하지 않았다.

## 실행과 결과

- `npm test`: 구현 담당이 69개(기존 하네스 32 + 제품 37) 통과, exit 0을 보고했다. 정확한 base/head의 독립 재검증 결과는 이 변경의 PR Evidence에 기록한다.
- 실제 HTTP 별도 시험: 참여자 목적지 변경 거절, 대표 목적지 전달, 시험 WAV 바이트 동일 전달, 같은 ID의 단일 저장, 종료 후 접근 차단·메모리 제거를 확인했다.
- 별도 브라우저 스크립트 실행: 공유방 생성·참여, 초대 fragment 제거, 목적지 수신, 과거 원음 자동 재생 제외, 새 원음 다운로드·디코딩·재생 완료, 녹음 취소, 15초 자동 전송, 수동 재생 중지, 모바일/오류 처리를 확인했다. 9개 시나리오 그룹이 통과했고 pageerror는 0개다.
- 최대 녹음은 실제 전송된 WAV 표본 기준 15,000ms였다. 마이크 입력과 발신자·목적지는 시험 자료다.

[구조화 결과와 당시 소스 해시](web-ui-qa.json)는 검증한 파일을 식별한다. 브라우저 스크립트와 실행 로그의 임시 경로는 총괄 작업 기록에 남겼으며 제품 런타임 의존성이 아니다. 재현할 기본 기능 순서는 [실행 문서](../README.md)를 따른다.
