# Dedicated AVD default API routing

The app default is4182; this isolated verification server uses4192. ADB reverse belongs to the live transport and disappears after emulator shutdown. The archived default-room-path-20261109/ files preserve the original failure, repair and endpoint verification without changing the app endpoint or existing room identity.

On this Mac, with the existing owned ADB5041, both approved AVDs/user10, task4192 and its4192 reverse already running, use `python3 ensure-default-route.py` from this directory. It adds only a missing4182→4192 mapping, refuses a conflicting mapping or absent server, preserves4192, prints a result and never overwrites archived evidence. It loads the existing ignored toolchain environment through root-ui-tools.py; no environment values or credentials are printed. It does not start servers, change APKs, grant permissions or modify rooms. New machines require their own explicit environment setup; this is not a portable deployment tool.

The original apply-default-route.py in the archived child directory is retained for audit. Use ensure-default-route.py for subsequent operation.
