## 목표

사용자가 차량 앱에서 지금 함께 가는 곳과 다음 행동을 바로 알아볼 수 있도록 화면과 한국어 문구를 단순화한다. 현재의 길고 반복되는 진단 설명·좌표·같은 모양 버튼 목록을 목적지 중심의 실제 UI로 바꾼다.

## 작업 종류

`prototype` — 사용자 직접 승인: “UI가 너무 안 직관적이고 별로다. 직관적이고 심플하게, 문구도 알아듣기 쉽게”.

## 수정 범위

- `DESIGN.md` 차량 UI 계약, `docs/product/vehicle-ui.md`, 필요한 차량 README 안내.
- `prototype/vehicle/app/src/main/kotlin/ai/pleos/destinations/vehicle/MainActivity.kt`, 새 UI 전용 view/presentation/copy 파일과 `app/src/main/res/**`.
- `ConvoySessionService.kt`는 필요한 알림 문구·표현만 허용하고 서비스·권한·동의·라우팅 수명은 유지.
- UI의 상태 오표시/행동 가드를 검증하는 필요한 `app/src/test/**`.
- 총괄 소유 새 증거 `prototype/vehicle/evidence/simple-ui/**`.
- core, 서버/프로토콜/저장소/SDK 호출 로직, 기존 증거·다른 worktree는 변경하지 않는다. 추가 라이브러리·계정·결제·계약·외부 메일·배포 없음.

## 완료 조건

- AC1: 연결된 홈의 첫 화면에서 현재 함께 가는 목적지(이름·주소), 짧고 사실에 맞는 상태, ‘목적지 바꾸기’, 동행 시작/중지를 알아볼 수 있다. 새 제안은 첫 화면에서 이름·이유·제안자 및 수락/거절이 보이며 스크롤 없이 응답 가능하다. 설정/좌표/ID/버전/SDK·긴 설명/예제 POI 선택은 기본 홈에서 보이지 않는다. 주요 동작에 시각적 우선순위를 주고 카드·여백·색/글꼴을 공통 token으로 관리한다.
